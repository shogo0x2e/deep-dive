# キーボードで試す夜の高速道路

`Assets/Scenes/Sandbox/HighwayKeyboard.unity` を開いて Play します。
Mac・Kinectなしで開始できる試遊用シーンです。Mainと同じ道路、交通、音、衝突演出のコードを使います。
Kinectの起動・ポーズ登録・Spout送信は行わず、通常のGame ViewとAudioListenerを使います。

| キー | 動作 |
|---|---|
| A / D、または ← / → | 左右に移動。離すと滑らかに横移動が止まる |
| W / S、または ↑ / ↓ | 加速 / ブレーキ。離すと速度を維持 |
| Space | 一時停止 / 再開 |
| R | 最初の高速・位置・開始速度・車配置へ戻す |
| H | 試遊HUDの表示切替 |

初速は138 km/h、標準の速度範囲は0〜220 km/hです。`NightHighway` → **Night Highway World > Ride > Maximum Speed Kmh** で上限を変更でき、10,000 km/hまで設定できます（初期220）。キーボード・Kinect・待機デモ・Rリセットに共通で適用されます。保持するにはPlay停止後に変更してシーンを保存してください。キーボードの最大加速は30 km/h毎秒、ブレーキは60 km/h毎秒で、Kinectの既定値と共通の速度更新処理を使います。左右移動は3.5 m/sです。Game Viewにキー入力のフォーカスを置いて操作してください。

速度をすぐ比較したい場合は、Play中に **Maximum Speed Kmh** を上げてから **Speed Kmh** に現在速度を直接入力できます。Mainの開始速度は **Kinect Arm Speed Input > Starting Speed Kmh** で設定します。別モードはありません。標準の加減速度は維持しています。極端な速度でも視野角は110度までに抑え、移動・衝突は10 m以下の区間に分割して処理します。

## 高速道路の乗り換え

最初の分岐は600 m先（初速のまま約16秒）です。標識の左側に次の高速、右側に現在の高速を表示します。

- 分岐地点で左車線にいると、左へ離れてから右へ曲がる準直結型の連絡ランプに入ります。
- 右車線にいると、そのまま現在の高速を走り続けます。
- 進路は分岐地点で確定します。その後の横移動では選び直しません。
- ランプ全体は約1,179 m。高架で本線と接続先の高速を越え、進行方向の左側で約300 m並走して降下し、約350 mの緩やかな区間で左側から合流します。対向車線を路面の高さで横切りません。次の分岐は2,600 m間隔です。
- HUDは現在の高速、分岐までの距離と、現在の車線で選ぶ進路を表示します。

分岐先の道路は選ぶ前から同じ位置に描画されます。カメラは道路の実距離に沿って進み、分岐・合流とも位置と向きが連続します。都市の建物も固定した世界座標に置いています。

架空の `BAYSHORE / HARBOR / SKYLINE / EAST LOOP` を巡る試作です。ランドマークはまだ追加していません。

## 車を避ける・ぶつかる

車は幅1.7 m・長さ4.8 mの立体ボディと屋根、窓、車輪、前後のライトを描画します。道路のカーブと勾配に沿って向きを変え、側面から追い越すときにも車の外形が見えます。

車の前後間隔と横位置はシード付きの乱数で決まります。車両プールは同方向18台・対向18台の計36台。各車に80〜120 km/hの速度をランダムに割り当て、プレイヤーの加減速とは無関係に、その速度を維持します。再配置でも同じ車IDの速度は変わりません。速度差によって車間が詰まったり横並びになったりするため、常に左右へ避けられる配置にはせず、必要ならブレーキで車間を取る遊び方です。

初期設定の **Dense Traffic** は通常設定で従来より約1.7倍の初期密度です。出現時の車間は最低90 m＋0〜20 mの乱数を基本に、標準の220 km/hを基準に、停止中の後方接近（最大120 km/h）、車体・プレイヤーの幅、0.8秒の反応時間、操作の平滑化を考慮して下限を計算します。速度上限や現在速度を変えても車間・初回配置は変わりません。Kinectの感度や横移動速度を下げる場合だけ、必要に応じて出現時の車間と初回車両までの距離を広げます。走行中の車間は各車の速度差で変わります。横操作が無効／極端に遅い設定では、以後の生成車両を直進できる通路の外へ配置します。見えている車の位置は変更しません。登録中の一時的な追跡抜けでは、車を消さず、操舵不能な間の衝突ダメージを抑制します。

`NightHighway` → **Night Highway World > Traffic > Dense Traffic** は初期ONです。OFFにすると従来の150 m＋0〜45 mを基本とする車間へ戻します（横移動が遅い設定では安全な下限を優先）。交通密度・操作感度の変更は今後の生成に適用し、見えている車の位置と固定速度は保ちます。

分岐の手前やランプで車を一括非表示にしません。各車は生成時の道路を保持し、自分がランプへ曲がっても本線の車はそのまま本線を走ります。対向車はランプへ載せず、元の本線または接続先の高速を走ります。再配置は車が後方または遠景の外へ抜けてから行い、新しい位置も視界外にします。分岐で旧道路へ離れた車も、見えなくなったら新しい道路の近い空き位置へ補充します。旧道路上の遠い車に引っ張られて何kmも先へ送ることはありません。前の表示フレームで見えていた車は、高速旋回の途中でも再配置しません。描画距離の外縁35%では車体・ライトを滑らかにフェードさせます。別の道路にいる車との架空の衝突・通過音は発生させません。Rで同じ配置に戻り、InspectorのSeedを変更すると別の配置を試せます。停止中は他の車だけが動き、Spaceによる一時停止では交通も止まります。

接触は描画と同じ車両位置を使い、前フレームからの移動区間で判定します。車の側面に寄る接触、後ろから追い越される場合にも対応します。衝突すると短い視点の揺れ、画面周辺の赤橙色の光、合成した衝突音が同時に出ます。1回の接触で連打しません。初期設定では衝突の瞬間に速度が30%落ちます（138 → 96.6 km/h）。接触中に毎フレーム減速することはありません。自動で元の速度には戻らず、WまたはKinectのアクセル操作で再加速します。ゲームオーバーはありません。

`NightHighway` の **Night Highway World > Collision Gameplay** で設定できます。MainとHighwayKeyboardの両シーンに初期値を保存しています。

| 設定 | 初期値 / 用途 |
|---|---|
| Collision Slowdown Enabled | ON。OFFで衝突時の減速だけを無効化し、音・ダメージ演出は残す |
| Collision Speed Loss Percent | 30。現在速度から失う割合（0〜100%） |

Play中もON/OFFと減速量を変更できます。翌回以降も使う設定はPlay停止後に変更してシーンを保存してください。Rで速度は開始時の値へ戻り、減速設定は維持します。

`HighwayImpactFeedback` の `ImpactStrength / ImpactVolume` で調整できます。衝突音は約0.5秒の鈍い低音で、初期 `Impact Volume` は0.85です。小さい接触でも聞こえる音量を確保し、Play開始時に音源を準備します。`Duck Ride Sound`（初期ON）は衝突直後に駆動音・通過音を25%まで下げ、約0.42秒で戻して低音同士の埋もれを抑えます。OFFにすると一時的な音量調整だけを無効化します。既存の `HighwayRideFeedback` の音・エフェクトON/OFFとMasterVolumeにも従います。

駆動音には低い推進音を重ねています。`HighwayRideFeedback` の `Bass Volume`（初期0.8）で低音の厚みを調整し、`Bass Enabled` で従来の音と比較できます。加速で厚く、ブレーキで弱まり、停止・一時停止ではフェードします。元のモーター音の大きさは `Motor Volume` で別に調整できます。

## シーンと再生成

MainにはKinect入力とSpout出力を残し、同じ衝突演出を接続しています。Sandboxで調整する道路・車・演出コードの変更はMainにも反映されます。Sandbox固有のHUDはMainへ追加しません。

メニュー `Tools > Highway Surfing > Open Keyboard Sandbox` から開けます。シーンがまだ存在しない場合にだけ `Create Keyboard Sandbox` で生成できます。既存のシーンは上書きしません。

## 検証

Unity 6000.3.26f1 のMac Editorで、道路・交通の数値チェックとPlay中のキーボード操作を検証しています。`HighwayRouteChecks.Run()` と `HighwayTrafficChecks.Run()` はEditor上で再実行できます。

- 道路1,900アサーションを通過。分岐・合流の位置と向きの連続性、実距離と走行速度、次の分岐の4通りの選択、既存道路の固定、左側からの並走合流、対向車線の上空通過、リセットを確認。
- 交通40項目を通過。24シードでの再現性・車ごとの固定速度、高速での通過、側面接触、停止中の追い越し、8 m/sへ横移動速度を調整した場合の判定を含む。
- 実際のInput Systemキーボードイベントを使うPlay検証18項目を通過。操舵、加減速、速度維持、一時停止、R、左右の経路選択、実車両接触からの演出を確認。
- 衝突音の事前準備、実出力の音量、全体のミックスの余裕、音・画面効果・一時的な走行音の減衰の切替を26項目で確認。同じ接触での重複発火もありません。音のチェックはPlay中に `Tools > Highway Surfing > Checks > Impact Audio (Play)` から再実行できます。
- コンパイルエラー・Play中の例外は0。スクリーンショット取得時のMetal警告、および音声デバイス変更時の再初期化警告を記録。衝突AudioSourceの出力は最終試験でも確認済み。

ローカルの試遊記録は `.Local/Review/highway-trial.txt`、画面は `Assets/.Local/Review/` にあります（Git対象外）。

衝突減速の実走検証は10,000 km/hも含む8シナリオ・42項目を通過しています。HighwayKeyboardをPlayして `Tools > Highway Surfing > Checks > Collision Slowdown (Play)` で再実行できます。実際の交通更新と接触イベントを使い、ON/OFF、30%・10%・100%、同速度での側面接触、停止中の後方接触、400/10,000 km/hでの接触、連続接触、再加速、リセットを確認します。結果はConsoleと `.Local/Review/highway-collision-trial.txt` に出力し、設定はテスト前の値へ戻します。

上限60/220/400/10,000 km/hでキーボード・共通腕入力・デモ・リセット・視野角・移動距離の32項目、交通1,440ケース、車の世界位置363,168サンプルと視界外再配置（速度上限別）を検証しました。

速度変更の検証はPlay中の `SpeedLimitChecks.Run()`、長時間の交通検証は `DenseTrafficChecks.Run()`、車の分岐前後の連続性と視界外再配置は `HighwayTrafficContinuityChecks.Run()` で再実行できます。`TrafficPopulationChecks.Run()` は500〜10,000 km/hで、旧道路の遠い車が補充を妨げないこと・合流後も前方に車がいること・表示中の車を保持することに加え、各30 km・12回の分岐を通る12条件で補充が続くことを検証します。

実Kinectの操作感、WindowsのSpout受信、外部スピーカーでの音量は今回のMac試遊では未検証です。


## 会場PCへの取り込み（2026-10-30版）

今回の道路拡張・車体・衝突・低音・減速の変更一式は `codex/highway-playtest` ブランチです。会場PCに既存の変更がある場合は、先に保存・コミットしてから切り替えてください。

```sh
git fetch origin
git switch codex/highway-playtest
git pull --ff-only origin codex/highway-playtest
```

Unity 6000.3.26f1で開き、Mac／Kinectなしは `Assets/Scenes/Sandbox/HighwayKeyboard.unity`、Windows／Kinectありは `Assets/Scenes/Main.unity` をPlayします。Kinect側の登録・運営手順は [PlayKinectHighway.md](PlayKinectHighway.md) を参照してください。減速を比較するときは、使用するシーンの `NightHighway` を選び、`Collision Slowdown Enabled` を切り替えます。
